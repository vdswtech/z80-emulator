Notes on the Z80 CPU

BIT SYMBOL NAME NOTES
8 S Sign Set if negative. Unset if positive.
7 Z Zero Set if zero. Unset otherwise.
6 F5 UNDOCUMENTED Copy of bit 5.
5 H Half Carry Set if carry from bit 3 to 4. Unset otherwise.
4 F3 UNDOCUMENTED Copy of bit 3.
3 P/V Parity/Overflow Set if there is an even number of bits set or an overflow. Unset otherwise.
2 N Add/Subtract Set if the last operation was subtraction. Unset if it was addition.
1 C Carry Set if result does not fit in the register. Unset otherwise.
