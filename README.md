# Z80 Emulator Project

## Goals 
The goal of this project is to explore making an emulator for the Z80 CPU. We are hoping to get experience writing an emulator and writing Z80 assembly, as it is something neither of us have done before. We are also interested in emulating the TI-83. 

## Build Requirements

To successfuly build this project, you need make and g++ with C++23 standard support. To compile the test suite you'll also need the gtest suite and we recommend having gdb.
